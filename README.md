# FourZero Dark & Light Mode

A lightweight WordPress plugin providing Light, Dark and System colour modes, with a native Elementor widget.

## Features

- Light, Dark and System modes
- Saves the visitor's preference in localStorage
- Follows OS dark-mode preference when System is selected
- Native Elementor widget
- Multiple Elementor widgets stay synchronised
- Pill, Compact and Switch styles
- Custom labels
- Elementor style controls
- No external libraries
- CSS helper classes for selective dark-mode styling

## Elementor

Activate the plugin and open Elementor. Search for **FourZero Light & Dark Mode** and drag the widget into your page, header or footer.

Useful CSS classes:

- `fz-dark-only`
- `fz-light-only`
- `fz-dark-surface`
- `fz-dark-button`
- `fz-dark-invert`
